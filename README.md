# PlayerPulser

Mobile-first cricket player trading app. Customers buy and sell whole Pulsers, track a portfolio, and move a simulated wallet. Admins manage players, users, the ledger, and payments from the same app.

Money is stored as integer paise. PostgreSQL is the source of truth. This build uses fictional development prices and simulated payments.

Start with [docs/setup-and-architecture.md](docs/setup-and-architecture.md). Product and money rules are in `docs/`.
